---
description: "Uruchom walidator formatu plików (kontrakt danych)"
---

Uruchom `python3 narzedzia/walidator.py`. Jeśli brakuje biblioteki PyYAML, zainstaluj ją (`pip install pyyaml`) i spróbuj ponownie.

Pokaż mi wynik w skrócie: liczbę plików, błędy (plik + opis) i ostrzeżenia. Jeśli są błędy, zaproponuj, który agent je naprawi, ale niczego nie zmieniaj bez mojej zgody.

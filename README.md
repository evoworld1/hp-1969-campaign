# Godzina, której nie było: kampania RPG (Hogwart, 1969)

Repozytorium robocze kampanii w świecie Harry'ego Pottera, prowadzonej na systemie *Harry Potter The Roleplaying Game* Neila Walkera (2. edycja, szkic z 02.04.2026). Treść tworzy zespół agentów Claude Code w sesjach w chmurze. Mistrz Gry podejmuje decyzje twórcze i akceptuje wyniki.

## Od czego zacząć
- **Pierwszy raz?** → `docs/START.md`
- **Jak pracować z agentami** → `docs/WORKFLOW.md`
- **Zasady projektu (dla agentów)** → `CLAUDE.md`
- **Format plików (dla panelu webowego)** → `docs/KONTRAKT-DANYCH.md`
- **Aktualny stan prac** → `04_kampania/stan-kampanii.md`

## Struktura
| Folder | Zawartość |
|---|---|
| `.claude/agents/` | Definicje 10 agentów |
| `.claude/commands/` | Komendy: `/faza`, `/scena`, `/przeglad`… |
| `docs/` | Kontrakt danych, workflow, słownik, szablony |
| `schemas/` | Wymagane pola dla każdego typu pliku |
| `narzedzia/` | Walidator i generator indeksu |
| `00_zrodla/` | Podręcznik Walkera i archiwum starego szkicu |
| `01_kanon/` | Świat 1969: fakty kanoniczne i nasze |
| `02_zasady/` | Streszczenie zasad Walkera, zasady domowe, mechaniki fabularne |
| `03_postacie/` | NPC i postacie graczy |
| `04_kampania/` | Stan kampanii, flagi, wątki, zarys |
| `05_scenariusze/` | Scenariusze, sceny, handouty |
| `06_sesje/` | Dzienniki rozegranych sesji |
| `99_robocze/` | Szkice, odrzucone warianty, podsumowania rozmów |

## Zastrzeżenie
Niekomercyjny projekt fanowski. Świat Harry'ego Pottera należy do J.K. Rowling i właścicieli praw. System RPG jest autorstwa Neila Walkera (darmowa praca fanowska).

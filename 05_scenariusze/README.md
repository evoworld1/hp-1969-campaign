# Scenariusze

Jeden folder na scenariusz:
- `przeglad.md` (typ `scenariusz`)
- `graf-scen.md`: mapa scen (Mermaid) i tabela flag (plik pomocniczy)
- `sceny/`: pliki typu `scena`, nazwa `NN-slug.md`
- `handouty/`: pliki typu `handout`
- `awaryjne.md`: przełączniki bezpieczeństwa i skróty (plik pomocniczy)
